## 理解 AI 智能体记忆

**AI 智能体的记忆**从本质上讲是指允许它们保留和回忆信息的机制。这些信息可以是关于对话的具体细节、用户偏好、过去的行动，甚至是学习到的模式。

没有记忆，AI 应用程序通常是无状态的，这意味着每次交互都从头开始。这会导致重复和令人沮丧的用户体验，因为智能体"忘记"了之前的上下文或偏好。

### 为什么记忆很重要？

智能体的智能与其回忆和利用过去信息的能力密切相关。记忆允许智能体：

• **反思**：从过去的行动和结果中学习。

• **互动**：在持续的对话中保持上下文。

• **主动和反应**：基于历史数据预测需求或做出适当的响应。

• **自主**：通过利用存储的知识更独立地运作。

实现记忆的目标是使智能体更加**可靠和有能力**。

### 记忆类型

#### 工作记忆

可以将其视为智能体在单个持续任务或思维过程中使用的便签纸。它保存计算下一步所需的即时信息。

对于 AI 智能体，工作记忆通常捕获对话中最相关的信息，即使完整的聊天历史很长或被截断。它专注于提取关键元素，如需求、建议、决策和行动。

**工作记忆示例**

在旅行预订智能体中，工作记忆可能捕获用户当前的请求，例如"我想预订去巴黎的旅行"。这个具体要求保存在智能体的即时上下文中，以指导当前的交互。

#### 短期记忆

这种类型的记忆在单个对话或会话期间保留信息。它是当前聊天的上下文，允许智能体参考对话中之前的回合。

**短期记忆示例**

如果用户问："飞往巴黎的航班要多少钱？"然后跟进："那里的住宿呢？"，短期记忆确保智能体知道在同一会话中"那里"指的是"巴黎"。

#### 长期记忆

这是在多个对话或会话中持续存在的信息。它允许智能体在较长时间内记住用户偏好、历史交互或一般知识。这对于个性化很重要。

**长期记忆示例**

长期记忆可能存储"Ben 喜欢滑雪和户外活动，喜欢有山景的咖啡，并且由于过去的受伤而希望避免高级滑雪场"。这些从之前交互中学习到的信息会影响未来旅行计划会话中的推荐，使其高度个性化。

#### 角色记忆

这种专门的记忆类型帮助智能体发展一致的"个性"或"角色"。它允许智能体记住关于自身或其预期角色的详细信息，使交互更加流畅和专注。

**角色记忆示例**

如果旅行智能体被设计为"专业滑雪规划师"，角色记忆可能会强化这一角色，影响其回应以符合专家的语气和知识。

#### 工作流/情景记忆

这种记忆存储智能体在复杂任务期间采取的步骤序列，包括成功和失败。这就像记住特定的"情景"或过去的经验以从中学习。

**情景记忆示例**

如果智能体尝试预订特定航班但因不可用而失败，情景记忆可以记录这一失败，允许智能体尝试替代航班或在后续尝试中以更知情的方式告知用户该问题。

#### 实体记忆

这涉及从对话中提取和记住特定实体（如人、地点或事物）和事件。它允许智能体构建对所讨论关键元素的结构化理解。

**实体记忆示例**

从关于过去旅行的对话中，智能体可能提取"巴黎"、"埃菲尔铁塔"和"在 Le Chat Noir 餐厅用餐"作为实体。在未来的交互中，智能体可以回忆起"Le Chat Noir"并主动提出在那里预订新的座位。

#### 结构化 RAG（检索增强生成）

虽然 RAG 是一种更广泛的技术，但"结构化 RAG"被强调为一种强大的记忆技术。它从各种来源（对话、电子邮件、图像）中提取密集的结构化信息，并使用它来增强响应的精度、召回率和速度。与仅依赖语义相似性的经典 RAG 不同，结构化 RAG 利用信息的固有结构。

**结构化 RAG 示例**

结构化 RAG 不仅匹配关键字，还可以从电子邮件中解析航班详情（目的地、日期、时间、航空公司）并以结构化方式存储它们。这允许进行精确的查询，如"我周二预订的飞往巴黎的航班是什么？"

## 实现和存储记忆

为 AI 智能体实现记忆涉及**记忆管理**的系统过程，包括生成、存储、检索、集成、更新，甚至"遗忘"（或删除）信息。检索是一个特别关键的方面。

### 专门的记忆工具

#### Mem0

存储和管理智能体记忆的一种方法是使用专门的工具，如 Mem0。Mem0 作为持久记忆层工作，允许智能体回忆相关交互，存储用户偏好和事实上下文，并从随时间的成功和失败中学习。这里的想法是将无状态智能体转变为有状态智能体。

它通过**两阶段记忆管道：提取和更新**来工作。首先，添加到智能体线程的消息被发送到 Mem0 服务，该服务使用大型语言模型 (LLM) 来总结对话历史并提取新的记忆。随后，由 LLM 驱动的更新阶段确定是否添加、修改或删除这些记忆，将它们存储在混合数据存储中，该存储可以包括向量、图和键值数据库。该系统还支持各种记忆类型，并可以合并图记忆来管理实体之间的关系。

#### Cognee

另一种强大的方法是使用**Cognee**，这是一个开源的 AI 智能体语义记忆，可将结构化和非结构化数据转换为由嵌入支持的可查询知识图谱。Cognee 提供**双存储架构**，结合向量相似性搜索和图关系，使智能体不仅理解什么信息相似，而且理解概念如何相互关联。

它擅长**混合检索**，融合了向量相似性、图结构和 LLM 推理——从原始块查找到图感知问答。该系统维护**活记忆**，随着时间的推移不断发展和增长，同时作为一个连接的图保持可查询性，支持短期会话上下文和长期持久记忆。

Cognee 笔记本教程（[13-agent-memory-cognee.ipynb](./13-agent-memory-cognee.ipynb)）展示了如何构建这个统一的记忆层，包括摄取各种数据源、可视化知识图谱以及使用为特定智能体需求定制的不同搜索策略进行查询的实际示例。

### 使用 RAG 存储记忆

除了像 mem0 这样的专门记忆工具外，您还可以利用强大的搜索服务，如**Azure AI Search 作为存储和检索记忆的后端**，特别是对于结构化 RAG。

这允许您使用自己的数据为智能体的响应提供基础，确保更相关和准确的答案。Azure AI Search 可用于存储用户特定的旅行记忆、产品目录或任何其他领域特定的知识。

Azure AI Search 支持**结构化 RAG** 等功能，擅长从大型数据集中提取和检索密集的结构化信息，如对话历史、电子邮件，甚至图像。与传统的文本分块和嵌入方法相比，这提供了"超人的精度和召回率"。

## 使 AI 智能体自我改进

自我改进型智能体的常见模式涉及引入**"知识智能体"**。这个单独的智能体观察用户和主要智能体之间的主要对话。它的角色是：

1. **识别有价值的信息**：确定对话的任何部分是否值得保存为一般知识或特定用户偏好。

2. **提取和总结**：从对话中提取本质的学习或偏好。

3. **存储在知识库中**：持久化提取的信息，通常存储在向量数据库中，以便以后可以检索。

4. **增强未来查询**：当用户发起新查询时，知识智能体检索相关的存储信息并将其附加到用户的提示中，为主要智能体提供关键上下文（类似于 RAG）。

### 记忆优化

• **延迟管理**：为了避免减慢用户交互，可以最初使用更便宜、更快的模型来快速检查信息是否值得存储或检索，仅在必要时调用更复杂的提取/检索过程。

• **知识库维护**：对于不断增长的知识库，可以将不太常用的信息移至"冷存储"以管理成本。
